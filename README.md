# Trialytix

## AI-powered Clinical Trial Success Prediction using Machine Learning

Trialytix is a machine learning-based web application that predicts the likelihood of success for clinical trials based on various trial features.

---

## Features

- Predicts clinical trial success
- Machine Learning model integration
- Flask-based web application
- User-friendly web interface
- Fast predictions

---

## Tech Stack

- Python
- Flask
- HTML
- Machine Learning
- Joblib
- Pandas
- NumPy
